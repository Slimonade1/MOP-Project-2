Projektet bruger Python biblioteket 'tkinter', 'subprocess' og 'os' til at skabe en GUI klient der kommunikerer med en C backend. Sørg for at have Python 3.8+ installeret, og en C compiler der kan producere en Windows executable (f.eks. MinGW-w64 eller MSYS2 'gcc').

Det burde blot være muligt at køre projektet ved at navigere til 'GUI version/python_gui' og køre:

```bash
python main.py
```
